# LibiFit 🏐💙

אפליקציית מעקב אימונים, כושר והתאוששות מותאמת אישית לליבי!

## ✨ מה כוללת האפליקציה?
* 📅 **יומן שבועי / חודשי / יומי (בסגנון Google Calendar):**
  - תצוגה שבועית נוחה עם חלוקת ימים וצבעים ייחודיים לכל סוג אימון:
    - 🏐 **כדורעף** (טורקיז עז)
    - 🏋️‍♀️ **חדר כושר** (כחול רויאל)
    - 🧗‍♀️ **טיפוס** (ירוק מנטה)
    - 🎾 **טניס** (ירוק ליים)
    - 🏃‍♀️ **אירובי / ריצה** (סגול)
    - 🧘‍♀️ **פילאטיס / יוגה** (ורוד)
    - ⭐ **ספורט אחר** (תכלת)
* 🏋️‍♀️ **אימוני חדר כושר ותבניות מוכנות (Templates):**
  - תבניות אימון קבועות שחוסכות זמן (סקוואט, היפ טראסט, מתח וכו')
  - טבלת סטים: משקל (ק"ג) או סימון "משקל גוף", מספר חזרות, וסימון ביצוע ✓
  - טיימר מנוחה בין סטים (30s, 60s, 90s, 120s) עם צליל התראה
* 🏐 **כדורעף ייעודי:**
  - רישום "עם מי שיחקתי" עם בחירה מהירה של חברות
  - שמירת קישור ישיר לווידאו של המשחק / אימון (לצפייה בלחיצת כפתור)
* 🧘‍♀️ **מדד התאוששות ומצב רוח יומי:**
  - סקר עייפות ואנרגיה מ-1 עד 10 עם גרדיאנט צבעים ויזואלי (מאדום לירוק/טורקיז)
  - סקר מצב רוח מ-1 עד 10 בנפרד
  - הערות גוף ושרירים תפוסים
* 🏆 **לוח שיאים והישגים (PRs):**
  - מעקב שיאי משקלים וחזרות (מתח, סקוואט, היפ טראסט, ניתור אנכי ועוד)
  - הוספת קטגוריות מותאמות אישית
  - שמירת היסטוריית תאריכים לכל שיא שנשבר
* 📱 **אפליקציית PWA מלאה לאנדרואיד:**
  - עובדת חלק בדפדפן כרום בטלפון
  - התקנה למסך הבית כאפליקציה רגילה (Add to Home screen)
  - שמירת נתונים מקומית במכשיר
  - הורדת קובץ גיבוי (JSON) ושחזור בלחיצת כפתור למניעת אובדן נתונים
